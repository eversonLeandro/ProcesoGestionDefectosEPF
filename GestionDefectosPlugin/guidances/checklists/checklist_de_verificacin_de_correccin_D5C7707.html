Checklist: Checklist de verificación de corrección
Lista de control para confirmar que un defecto quedó realmente resuelto antes de cerrarlo.

Main Description

Este checklist se usa al ejecutar la tarea Verificar corrección. El tester debe confirmar cada punto antes de entregar la Evidencia de prueba. Si algún punto falla, el defecto regresa a Corregir defecto.

  • Se repitieron los pasos originales del reporte y el defecto ya no ocurre.
  • La verificación se hizo en el mismo entorno y versión donde se reportó.
  • Se ejecutaron las pruebas de regresión relacionadas con el componente corregido.
  • No aparecieron fallos nuevos en funcionalidades vecinas.
  • La corrección fue revisada por una persona distinta a quien la implementó.
  • El resultado y la evidencia (capturas o registros) quedaron adjuntos.
  • El estado del defecto fue actualizado de acuerdo con el resultado.
