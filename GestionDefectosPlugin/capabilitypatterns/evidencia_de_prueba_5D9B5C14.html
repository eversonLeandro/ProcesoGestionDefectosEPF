Main Description

La Evidencia de prueba es el resultado de la tarea Verificar corrección. Sirve de base para decidir si el defecto se cierra o si debe regresar a corrección.

Contenido: pasos originales repetidos y su resultado, pruebas de regresión ejecutadas, entorno y versión usados, capturas o registros de respaldo, y veredicto final (aprobado o rechazado).
