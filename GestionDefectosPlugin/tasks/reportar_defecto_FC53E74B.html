Task: Reportar defecto
Registrar un defecto de forma completa y reproducible.
Purpose
Dejar constancia del defecto con la información suficiente para que otra persona pueda reproducirlo y atenderlo.
Relationships
RolesPrimary Performer:
  • Reportante
Additional Performers:
Outputs
  • Reporte de defecto
    Process Usage
    • Gestion de Defectos  >  Registro y triage  >  Reportar defecto
    • Registro y triage  >  Reportar defecto
    Main Description
    El Reportante registra el defecto usando la plantilla de reporte. Antes de crearlo debe confirmar que se trata realmente de un defecto y que no fue reportado antes.
    Steps
    Confirmar el defecto
    verificar que es un comportamiento incorrecto y que no está ya reportado.
    Describir los pasos para reproducirlo
    una lista numerada desde el estado inicial.
    resultado obtenido
    Indicar resultado esperado y obtenido.
    Adjuntar la evidencia
    capturas, videos o registros.
    Registro de estado
    Registrar el reporte con estado "Nuevo".
    New Step
