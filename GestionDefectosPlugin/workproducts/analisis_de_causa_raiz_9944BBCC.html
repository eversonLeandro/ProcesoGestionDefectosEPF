Description
Main Description

Este work product documenta el resultado de la tarea Analizar causa raíz. Permite que la corrección ataque el origen del problema y no solo el síntoma, y deja un registro útil para evitar que el defecto se repita.

Contenido: confirmación de que el defecto se reprodujo, componente o módulo responsable, causa identificada, factores que contribuyeron (por ejemplo, un requisito ambiguo o una validación ausente) y recomendación para la corrección.
